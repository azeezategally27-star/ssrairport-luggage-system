# Trolley Processes 3D Demo

This Electron app simulates trolley operations with smooth 3D animations for your presentation.

Run:

- cd frontend_trolley_3d
- npm install
- npm run start

Notes:
- This is a lightweight demo using Three.js and procedural geometry to keep dependencies small.
- If you want higher fidelity, we can swap the box geometry for glTF trolley models and add PBR materials.
