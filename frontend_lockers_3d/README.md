# Smart Lockers 3D Digital Twin

Run the demo locally (Electron + Three.js):

Prerequisites: Node.js and npm

Commands:
  cd frontend_lockers_3d
  npm install
  npm run start

What to try:
- Change grid size (rows/cols/levels) and apply.
- Click a locker to select it. Use the left panel actions to open, set priority, or toggle maintenance.
- Simulate bookings and export config/logs for your report.

Notes:
- This is a demo with simulated bookings and basic local persistence (export only). For production, add a backend with authentication, payment integration, and NFC/QR hardware support.
